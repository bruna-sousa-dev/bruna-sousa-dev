## 🚀 Projetos em destaque

### IoT Data Intelligence Platform

Plataforma full stack para transformação de dados IoT em informações úteis para análise, monitoramento e tomada de decisão.

**Stack:** Python, FastAPI, SQLAlchemy, PostgreSQL, React, Pandas, Docker, Nginx e IA.

[Ver repositório](https://github.com/bruna-sousa-dev/iot-data-intelligence-platform)

---

### Fast Movie API

API REST para operações CRUD de filmes.

**Stack:** Python, FastAPI, SQLAlchemy, Alembic, SQLite, Pydantic, Ruff, MkDocs.

[Ver repositório](https://github.com/bruna-sousa-dev/fast-movie-api)

---

### Authentication Web App With Database

Esta aplicação consiste em uma API RESTful desenvolvida com Flask. O frontend é uma interface web estática (HTML, CSS, JS) que interage com a API para permitir que os usuários testem o sistema e tenham uma boa experiência com este tipo de aplicação.

**Stack:** Python, Flask, SQLAlchemy, Migrations, SQLite, HTML, CSS, JavaScript, Docker, Gunicorn, Render, GitHub Pages

[Ver repositório](https://github.com/bruna-sousa-dev/authentication-web-app-with-database)
